# Tools
- [`inference/`](inference/) — Megatron and vLLM Slurm servers, disaggregated prefill/decode, and a shared HTTP client.
- [`conversion/`](conversion/) — model-agnostic Megatron-Bridge `AutoBridge` checkpoint export launcher.
- [`merge/`](merge/) — Megatron backend for distributed checkpoint merging.
- [`gym_data/`](gym_data/) — one-time NeMo Gym environment preparation: server venvs, the NemoGym actor venv, and the collated dataset.
